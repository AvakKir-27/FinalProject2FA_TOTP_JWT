# Веб-приложение с двухфакторной аутентификацией (TOTP)

## Краткое описание проекта
Веб-приложение с безопасной двухфакторной аутентификацией на базе стандарта TOTP (Time-based One-Time Password). Система обеспечивает защищённый доступ к внутренним ресурсам организации с использованием двухэтапной проверки: логин/пароль + одноразовый код из мобильного приложения.

## Технологический стек
- **Бэкенд**: Spring Boot 3, Spring Security, Spring Data JPA
- **Аутентификация**: JWT (JSON Web Tokens), TOTP (Google Authenticator)
- **База данных**: MySQL
- **Фронтенд**: Чистый HTML5, CSS3, JavaScript (без фреймворков)
- **Безопасность**: BCrypt, XOR+Base64 шифрование

## Основные функции
1. Двухэтапная аутентификация пользователей (логин+пароль → TOTP код)
2. Административная панель управления пользователями
3. Автоматическая генерация и шифрование TOTP-секретов
4. Создание QR-кодов для настройки мобильных аутентификаторов
5. Защита всех API эндпоинтов JWT токенами
6. Генерация временных паролей доступа к серверу

**Архитектура**: Модульное Spring Boot приложение с REST API, stateless аутентификацией и клиент-серверной архитектурой.

## Инструкция по запуску

### Требования:
- Java 17 или выше
- Maven 3.8+
- MySQL 8.0+ (опционально)

### Запуск с MySQL:
1. Установить и запустить MySQL
2. Создать базу данных: 
   ```sql
   CREATE DATABASE 2fa_db;
   ```
3. Обновить `application.properties`:
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/auth_db
   spring.datasource.username=ваш_логин
   spring.datasource.password=ваш_пароль
   ```
4. Запустить приложение:
   ```bash
   mvn spring-boot:run
   ```

### Доступные страницы:
- `http://localhost:8080/login.html` - Вход в систему
- `http://localhost:8080/put_totp.html` - Ввод TOTP кода
- `http://localhost:8080/index.html` - Главная страница
- `http://localhost:8080/users.html` - Админ-панель (только для админов)

## Список REST API эндпоинтов

### Публичные (без аутентификации):
- `POST /auth/login` - Первый этап аутентификации (логин/пароль)
- `POST /auth/verify-totp` - Второй этап аутентификации (TOTP код)

### Защищённые (требуется JWT):

#### Управление пользователями:
- `GET /api/admin/users` - Получить список всех пользователей
- `POST /api/admin/users` - Создать нового пользователя
- `DELETE /api/admin/users/{id}` - Удалить пользователя по ID
- `GET /api/admin/users/{id}/qr` - Получить QR-код пользователя

#### Сервисные функции:
- `GET /api/server/password` - Получить временный пароль сервера

## Примеры запросов

### Вход:
```http
POST /auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "2324"
}
```

### Проверка TOTP:
```http
POST /auth/verify-totp
Content-Type: application/json

{
  "auth_token": "временный_токен",
  "totp_code": "123456"
}
```

### Создание пользователя:
```http
POST /api/admin/users
Authorization: Bearer ваш_jwt_токен
Content-Type: application/json

{
  "username": "новый_пользователь",
  "password": "пароль123"
}
```

## Основные компоненты системы

### 1. Контроллеры:
- **AuthenticationController** - Обработка двухэтапной аутентификации
- **AdminPanelController** - Управление пользователями через админ-панель
- **ServerPasswordController** - Генерация временных паролей сервера

### 2. Сервисы:
- **UserManagementService** - Бизнес-логика управления пользователями
- **TotpAuthenticationService** - Работа с TOTP (генерация, проверка, QR)
- **JwtTokenService** - Создание и проверка JWT токенов
- **TemporaryTokenService** - Временные токены для второго этапа аутентификации

### 3. Безопасность:
- **SecurityConfig** - Конфигурация Spring Security
- **JwtAuthenticationFilter** - Кастомный фильтр для проверки JWT
- **SecurityTotpAuthCode** - Шифрование TOTP-секретов

### 4. Модели и DTO:
- **User** - Сущность пользователя в БД
- **UserDTO, TotpLoginRequestDTO, JwtResponseDTO** - Объекты передачи данных

## Принципы работы

### Процесс аутентификации:
1. Пользователь вводит логин/пароль → `POST /auth/login`
2. Система проверяет пароль → возвращает временный токен (5 минут)
3. Если первый вход → показывает QR-код для настройки 2FA
4. Пользователь вводит TOTP код → `POST /auth/verify-totp`
5. Система проверяет код → активирует 2FA → выдает JWT токен
6. Редирект: ADMIN → `/users.html`, USER → `/index.html`

### Управление пользователями:
- Только администратор может создавать/удалять пользователей
- При создании автоматически генерируется TOTP-секрет
- Секрет шифруется (XOR+Base64) перед сохранением в БД
- Пароли хранятся в виде BCrypt хэшей

### Безопасность:
- Все API эндпоинты защищены JWT токенами
- TOTP-секреты шифруются в базе данных
- Защита от brute-force: 5 неудачных попыток → блокировка 15 минут
- Stateless аутентификация (нет серверных сессий)

## Тестирование системы

### Тестовые данные:
- **Администратор**: `admin` / `admin123`
- **TOTP код**: Использовать Google Authenticator/Яндекс.Ключ

### Проверка работы:
1. Войти как admin → настроить 2FA через QR-код
2. Создать тестового пользователя через админ-панель
3. Выйти и войти под тестовым пользователем
4. Проверить доступ к защищённым ресурсам
